# Env Template Source Excerpt

Sample fixture material for safe environment setup output.

```text
DELIBERUM_ENABLE_OPENAI_COMPATIBLE_PROFILE=true
# DELIBERUM_OPENAI_API_KEY=<set in local daemon environment>
DELIBERUM_OPENAI_BASE_URL=<non-secret provider base URL>
```

The template exposes enable flags and non-secret routing fields. Secret values remain commented placeholders for local operator entry.
